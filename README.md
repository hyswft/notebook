记事本 · 离线版

【方式一：单个文件，最简单】
把 index.html 复制到电脑上，用 Chrome、Edge 或 Safari 打开即可使用，不需要联网。
记录保存在这个浏览器里。请始终用同一个浏览器、同一个位置的文件打开。

【方式二：安装成手机/电脑上的应用（推荐，iPhone 和安卓都适用）】
1. 把整个文件夹免费放到网上，例如：
   - Netlify Drop（app.netlify.com/drop）：把文件夹拖进网页即可，得到一个网址
   - 或 GitHub Pages
2. 在每台设备上用浏览器打开这个网址：
   - iPhone / iPad：Safari →「分享」→「添加到主屏幕」
   - 安卓：Chrome → 菜单 →「安装应用」或「添加到主屏幕」
   - Mac / Windows：Chrome 或 Edge 地址栏右侧的「安装」图标
3. 打开过一次后，断网也能正常使用。网站只提供程序本身，你的记录只保存在各自设备上，不会上传。

【在设备之间转移】
设置（右上角下载图标）→「导出备份」，把 .json 文件通过 AirDrop、微信文件传输、网盘、邮件等发到另一台设备，再在那里「导入备份」。导入会合并内容，保留较新的版本，不会删除记录。

【请注意】
- 清除浏览器数据或卸载应用会删除记录，请定期导出备份。
- 「导出为可读文本」生成 .md 文件，用任何文本编辑器都能阅读，适合长期存档。
